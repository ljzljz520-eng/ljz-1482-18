# 验收场景矩阵

| 场景 | 前端表现 | 后端/持久化保证 |
|---|---|---|
| 非法深链接 | 展示非法项目、场次、素材或导出链接错误页，不映射编辑对象 | 正则校验失败返回 400，不进入资源查询 |
| 猜到他人项目/资源 ID | 显示无权限或不存在；本地草稿隔离，不展示内容 | 每个接口先查 Membership，再校验资源 `projectId`；未授权返回 404 |
| 项目退役 | 工作台显示退役状态和历史导出，普通写入入口禁用 | 写接口要求 ACTIVE；导出快照仍可按成员权限读取 |
| 旧节点迁移 | 显示当前模块、目标模块和管理员迁移操作 | 事务更新 Project 模块版本并写入 ModuleMigration；非管理员不可迁移 |
| 登录会话过期 | 401 后清理登录态并跳转登录页，登录后回到原 `returnTo` | JWT 失效后所有接口拒绝；前端守卫不作为权限依据 |
| 浏览器后退 | 地址栏、步骤和编辑对象按新 URL 重新验证加载 | 子资源接口再次校验项目归属、删除状态和权限 |
| 快速切换项目 | 骨架屏替换旧内容；旧请求被取消或按代次丢弃 | 每个接口以 URL 中的项目为作用域，返回不跨项目复用 |
| 保存响应乱序 | token + 资源键过滤迟到响应；旧响应不覆盖新页面 | 版本号乐观锁与事务防止乱序覆盖服务器版本 |
| 服务器已有新稿 | 显示冲突和服务器新稿，只允许人工选择或合并 | `expectedVersion` 不一致返回 409，不执行写入 |
| 场次/素材删除 | 深链接显示资源已删除/不存在 | `deletedAt` 持久存储，普通列表和详情过滤软删数据 |
| 历史导出链接 | 打开冻结时的标签、脚本和版本 | ExportSnapshot 不可通过普通保存修改，不导向最新草稿 |
| 权限收回 | 本地草稿移动到 revoked 分区，不渲染私有文本 | 重新访问接口仍被 Membership 拦截 |
